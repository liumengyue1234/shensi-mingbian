# 演示说明

## 系统演示流程

### 场景一：法律咨询（双擎联动）

**用户输入**：
```
我是外卖骑手，送餐途中发生交通事故受伤，能申请工伤认定吗？
```

**系统处理**：
1. 调用得理法规API（语义检索）→ 检索到《工伺保险条例》第14条、《关于外卖骑手工伤认定的指导意见》等
2. 调用得理案例API → 匹配3个类似外卖骑手工伤案例
3. 混元大模型综合分析 → 生成有据可查的法律意见

**系统回复示例**：
> 根据《工伤保险条例》第14条第(六)项的规定，职工在上下班途中受到非本人主要责任的交通事故伤害，应认定为工伤。
>
> 您作为外卖骑手，若与平台存在劳动关系，则在送餐途中（视为工作时间）发生的交通事故，符合工伤认定条件。
>
> **参考案例**：
> - 李某某诉XX外卖平台工伤认定案（2022年，上海市人社局） - 认定为工伤
> ...

### 场景二：诉讼策略推演

**用户上传起诉状**（示例片段）：
```
原告：张三，男，1985年生
被告：某科技有限公司

诉讼请求：
1. 请求法院判令被告支付违法解除劳动合同赔偿金 60,000 元
2. 请求法院判令被告补缴社会保险费

事实与理由：
原告于2020年3月入职被告公司，担任软件工程师。
2023年10月，被告以"严重违反公司规章制度"为由解除劳动合同...
```

**系统切换"对方律师"视角，生成**：

```markdown
## 质证意见清单

1. **关于违法解除的认定**
   原告主张被告"违法解除"，但未提供公司规章制度的具体条款。
   建议质疑：被告是否履行了民主程序制定规章制度？原告是否知晓相关规定？

2. **关于赔偿金计算基数**
   原告主张 60,000 元，需核实月工资基数是否准确...

## 风险提示
- 若法院认定解除行为违法，赔偿金 = 月工资 × 工作年限 × 2
- 社会保险补缴诉求属于劳动争议范畴，需先经仲裁前置...

## 诉讼策略建议
1. 收集公司规章制度违规操作的书面证据
2. 考虑提出反诉：员工是否存在泄露商业秘密情形...
```

## 快速体验

### 接口测试

```bash
# 1. 健康检查
curl http://localhost:5000/api/health

# 2. 法律问答
curl -X POST http://localhost:5000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"query": "合同违约金最高可以约定多少？", "session_id": "demo"}'

# 3. 类案检索
curl -X POST http://localhost:5000/api/case/search \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["房屋买卖合同", "定金"], "page_size": 3}'

# 4. 法条检索
curl -X POST http://localhost:5000/api/law/search \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["婚姻法财产分割"], "field_name": "semantic"}'
```
