## 核心模块说明

### 1. 对话式问答引擎 (QAEngine)
- **双擎联动**：同步调用得理法规API和案例API，构建检索增强上下文
- **多轮对话**：内置会话管理，支持上下文关联的多轮法律咨询
- **混元驱动**：将检索结果注入混元大模型，生成准确、有据可查的法律回答

### 2. 相似案例匹配引擎 (CaseRetrievalEngine)
- 支持**关键词**和**语义**两种检索模式
- 可按法院层级、裁判年份、文书类型精确过滤
- 自动生成结构化类案检索报告

### 3. 精准法条检索引擎 (LawRetrievalEngine)
- 语义检索：直接输入法律问题，智能匹配相关法条
- 关键词检索：精确定位法规名称
- 支持获取法规全文详情

### 4. 诉讼策略推演引擎 (StrategyEngine)
- 切换"对方律师"视角，对起诉状进行对抗性分析
- 生成质证意见清单、风险提示和诉讼策略报告
- 支持民事、刑事、行政三类案件

## 技术选型

| 组件 | 技术方案 |
|------|---------|
| 认知引擎 | 腾讯混元大模型（通过元器智能体API） |
| 法律知识库 | 得理开放平台（案例库+法规库） |
| 智能体编排 | 腾讯元器工作流 |
| 后端框架 | Python Flask |
| 导出功能 | 腾讯文档 Open API |
